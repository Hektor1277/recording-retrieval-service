# 项目背景

项目目标是把父项目给出的粗粒度版本条目，自动检索为高质量的版本资源链接与辅助信息，优先拿到 `YouTube`、`Bilibili`，其后再考虑 `Apple Music` 等辅助平台。

当前检索服务的核心要求：
- 支持单条请求，也支持父项目通过接口并发调用多条版本请求
- 单条内部允许多站点并发搜索
- 不同条目之间的访问统计、告警和缓存必须隔离
- 在没有稳定付费 API 可长期依赖的前提下，网页检索路径必须尽可能稳

本轮之前的主要问题：
- `Bilibili` 搜索链路在匿名或弱上下文状态下不稳定
- `exact-link` 排序在“同版不同上传”上容易被错误上传压住
- 长批次回归中，部分场景会因链路抖动或查询模板问题回退
